修复已部署到 10.0.9.1（0.1.1）。两个页签目标地址及激活状态、状态 JSON 和 `pkg check -s` 均通过验证。浏览器交互复查因电脑控制工具返回 `cgWindowNotFound` 未完成；没有将此记为浏览器点击测试通过。

## 0.1.5 设备温度上报

新增 `deviceTemp` 摄氏温度字段，优先最高 CPU 核心温度，回退到最高 ACPI 热区温度。独立线程每 10 秒读取，0.5 秒读取超时，不阻塞 GPS 采集；缺失、异常或超过 30 秒的温度不加入上报。温度在位置入队时固定，补传不重新读取。状态页新增温度及来源。

目标机 28 项测试通过，包含 CPU 优先级、ACPI 回退、忽略温度阈值、传感器缺失/异常/超时、温度过期和 HTTP 表单字段验证。0.1.5 部署后，真实位置日志包含 `deviceTemp: 47.1`，来源 ACPI；该次采集后的缓存清零，接收接口 HTTP 200。原生页面回归与包文件校验通过。尚未读取 Traccar 服务端数据库验证其最终字段存储。
