## 前端变化

在原状态页顶部新增独立面板，保留卫星图、原始信号明细、详细运行参数、日志与服务控制。

- 大字和颜色显示**实际采用的定位**；独立徽标显示**求解器原始 FIX/FLOAT**。未通过门槛的原始 FIX 不显示为已采用 FIX。
- 六个数值卡片和门槛进度条：水平标准差、垂直标准差、ratio、差分新鲜度、RTK 卫星数、解算新鲜度。门槛来自配置；标准差明确标注不是实测误差。
- 数据链路灯显示本机 MSM、NTRIP 差分、解算更新与 RTK 采纳是否就绪。
- 最近五分钟来源时间带、FIX 样本占比和连续 FIX 时长只统计本页面已观察的窗口。不足三个样本显示“积累中”。网络空档不当作连续 FIX，服务重启清空窗口。
- 过期、停止和请求失败时面板灰化，历史 FIX 不保持绿色有效状态；不加载外部图表库或 CDN。
