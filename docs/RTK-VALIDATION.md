# LC76G 软件 RTK 部署验证（2026-11-18）

项目版本 0.3.0；测试目标 `10.0.9.1`，pfSense CE 2.9.0 / amd64 / FreeBSD 16 / Python 3.11。未修改防火墙、路由、VPN 或内核驱动，未重启 pfSense。

## 已应用配置

- LC76G 与应用：230400 baud。通过 PAIR864 设置、PAIR023 模组软件重启，再在 230400 下验证 PAIR865 回复及多个前进的 RMC 历元。
- 唯一采集进程在连接时启用 MSM7 与广播星历。实际验证消息：1077、1087、1097、1117、1127；1019、1020、1042、1044、1046，均经过 CRC24Q 校验。
- Caster：`rtk.ntrip.qxwz.com:8002`，首选 `AUTO`、备用 `RTCM32_GGB`。用户原给 8082 在本机与 pfSense 均超时，经用户确认改为 8002；账户认证和真实差分接收成功。
- 差分中实际观测到 1005、1033、1074、1084、1124。账户参数只存于 pfSense 配置和 0600 运行配置，不进入仓库、安装包、状态、队列或命令行。
- 采用 RTKLIB L1 单频动态解算，有效 FIX/FLOAT 优先；超龄、输入断开、标准差超限或解算失效回退 GGA。GGA 同时无效则不新增定位。
- 设置已写入 `installedpackages/traccar/settings` 并生成运行配置；保留原 Traccar、APRS 端点、身份和已有队列。

## 构建与验证

RTKLIB 固定提交 `180043ee24b6d2b168f98b64be15f69d50046b1a`，在独立 FreeBSD 16 构建虚拟机编译，在目标系统验证运行。补丁增加 `-n` 无终端模式，关闭本地/远程交互控制台；原生程序不持有 USB 或账户。三个环回 TCP 通道传输本机观测、基站差分和解算结果。

- 目标机运行 **53 项测试，全部通过**。包含原上报/缓存/USB 重连测试，以及混合流逐字节分片、已知 CRC 检查值、损坏帧恢复、环回 NTRIP、认证错误脱敏、RTK 时效/标准差/ratio 门槛、GGA 回退、来源切换不回放旧时间戳。
- 原生测试验证后台启动、两条输入连接、空闲超过旧 5 秒超时仍保持进程、异常终止后重新启动、干净关闭。测试仅使用环回，不发送模拟坐标到真实服务器。
- 系统、Traccar、APRS、RTK、状态五个原生页面及状态 JSON 通过渲染测试。RTK 页面密码不回显；重新保存该页保留账户、230400 波特率及其他通道设置。
- 实机暂将运行配置的差分端口改为不可达端口，验证 GGA 持续有效、MSM 持续接收、Traccar 返回 HTTP 200；随后从持久配置恢复 8002。没有更改持久配置中的正确端口。
- 实机终止解算子进程，验证采集父进程保持运行、有效 GGA 回退持续、原生解算器自动重启。
- 最终安装包通过 `pkg check -s pfSense-pkg-Traccar` 文件校验。构建脚本显式处理 Windows 源文件的 CRLF 和执行权限，避免生成不可运行的 FreeBSD 启动脚本。

## 实际解算结论

已产生真实 RTK FLOAT：示例参与解算 6 星、水平标准差约 5.70 m、垂直约 6.01 m、差分龄期 1 s、ratio 1.5。该结果超过默认水平 3 m / 垂直 6 m 门槛，且有时停止更新，因而未作为上报位置，系统使用有效 GGA。

诊断期原生跟踪显示部分历元单点初始化的伪距残差未通过卡方检查。收敛不稳定，未降低独立输出质量门槛来强行采用弱结果。后续应在开阔环境、天线可靠安装后验证收敛和实际误差。

最终 60 秒连续实测，每 5 秒采样共 12 次均定位有效：11 次采用 GGA，1 次采用通过全部门槛的 `rtk_fix`。随后解算回到不确定度较大的 FLOAT，自动使用 GGA。不能将短暂 FIX 认定为持续厘米级精度，也没有外部真值验证其实际误差。

此轮新增 591 帧本机有效 RTCM、1 帧 CRC 错误及 188 字节丢弃；损坏帧没有送入解算器。五星座 MSM 与星历持续接收，NTRIP 为 streaming、累计 518 帧有效差分，Traccar HTTP 200，Traccar/APRS 队列均为 0。偶发串口损坏尚未完全消除，帧校验、时效与质量门槛防止使用受损或过期结果。

安装包 SHA256：`2ad9d08a7700cf3b402cab1c45cd6ea1ffdec81913cb4e5823c036843e21d9ef`；下载到本机后与目标机一致。

WGS84 / 参考历元 2005.0 是用户提供的千寻服务元数据；软件不执行历元或坐标框架转换。RTK 椭球高只在有同历元 GGA 大地水准面差时转换为 GGA 的高度基准，否则省略高度。
